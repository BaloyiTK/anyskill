# AnySkill Customer UI Flow — 15 Screens

Status: Design review

These filenames define the approved customer-flow sequence. Individual image assets have been generated separately and should use these exact names.

1. `01-splash.png` — Brand splash
2. `02-onboarding-find-nearby.png` — Find skilled people nearby
3. `03-onboarding-confidence.png` — Profiles, reviews, verification, price and distance
4. `04-onboarding-get-job-done.png` — Request, communicate, complete and review
5. `05-welcome-auth.png` — Create account / log in
6. `06-home.png` — Customer home and popular skills
7. `07-skill-search.png` — Search/select a skill
8. `08-location-radius.png` — Location and search radius
9. `09-worker-results.png` — Nearby worker results
10. `10-worker-profile.png` — Worker details, trust and portfolio
11. `11-request-job.png` — Job details, photos, date/time and budget
12. `12-review-request.png` — Review before sending
13. `13-request-sent.png` — Request submitted / waiting
14. `14-job-accepted-active.png` — Accepted and active-job state
15. `15-complete-review.png` — Completion, rating and review

## Flow

Splash → Onboarding 1 → Onboarding 2 → Onboarding 3 → Welcome/Auth → Home → Skill Search → Location & Radius → Worker Results → Worker Profile → Request Job → Review Request → Request Sent → Job Accepted/Active → Complete & Review

## Design system

- Primary: deep AnySkill green
- Accent: warm gold/yellow
- Background: white / warm off-white
- Rounded cards and controls
- Mobile-first, iOS-style presentation mockups
- Trust cues: verification, ratings, availability and distance
- South African currency examples use R (rand)

Implementation should begin only after design review/approval.
